# S5：MCP Kotlin SDK 在 Android 上（精简版，C7a）

- **状态**：结论已定；Binder 部分已验证（JVM 单元测试、API 36 模拟器跨进程、R8 release）。远端 Streamable HTTP 不在这次范围内，未做。
- **日期**：2026-10-07
- **范围**：按整合人对 C7 的要求精简：确定能不能用官方 MCP Kotlin SDK、版本怎么锁；不行就自己写一层只做 tools 的 MCP JSON-RPC，公开接口按 [docs/sample-apps.md](../sample-apps.md) 第 3 节不变。
- **解锁**：W15（`sdk/plugin-sdk`），W14 的 Extension Host 客户端

## 结论

**不引入官方 MCP Kotlin SDK。`sdk/plugin-sdk` 自己实现 MCP 的 tools 子集**，跑在 binder-channel-v1 上；公开接口（`McpBinderService`、`McpToolRegistry`、`McpToolAnnotations`、`McpToolResult`、`McpBinderTransport`、`McpBinderClient`）与草案一致。没有新增任何依赖，`gradle/libs.versions.toml` 不变（只更新了注释）。

原因：官方 SDK 每个还在维护的版本都要求更新的 `kotlinx-serialization-json` 和 `kotlinx-io`，而这两个与 ACP 0.30.1 共用、锁在 1.7.3 / 0.5.4（ACP 0.30.1 就是按这两个版本构建的）。按整合人的规则，与 ACP 0.30.1 冲突时不升级。

## 自己实现的部分

代码在 `sdk/plugin-sdk`（`internal/McpJsonRpc.kt`、`internal/McpServerSession.kt`、`McpBinderClient.kt`、`McpBinderService.kt`、`McpBinderTransport.kt`）。

- **协议修订版**：实现 `2025-06-18`（`structuredContent`、`title`、工具注解都在这一版里），也接受客户端请求 `2025-03-26`、`2024-11-05`；tools 部分在这几版之间没有不兼容的变化。两端都是我们自己的代码，按请求方给的版本回答，不认识就回 `2025-06-18`。2026-07-28 修订版（去掉协议层会话）这次没有评估；Binder 通道一条就是一次连接，以后切换只影响 `initialize` 的处理。
- **消息**：JSON-RPC 2.0，不支持批量（2025-06-18 去掉了批量）；用 `kotlinx-serialization-json` 的 `JsonElement` 手工编解码，不需要 serialization 编译插件。
- **方法**：`initialize`、`notifications/initialized`、`ping`（双向）、`tools/list`（客户端自动翻页，服务端一次返回全部）、`tools/call`、`notifications/cancelled`（双向）、`notifications/tools/list_changed`。其他请求回 `-32601`；服务端发来的 sampling、roots、elicitation 请求客户端一律回 `-32601`。
- **生命周期**：`initialize` 之前服务端只接受 `initialize` 和 `ping`，`tools/*` 回 `-32600`。
- **取消**：调用方协程取消或超时 → 客户端发 `notifications/cancelled` → 服务端取消 handler，并且不再回这个请求的响应。
- **错误**：未知工具、参数不是对象 → `-32602`（协议错误，工具没有执行）；handler 抛异常 → `isError=true` 的结果，Service 不崩。
- **单条上限**：与 ACP 相同，`ChannelConfig.DEFAULT.maxMessageChars` = 65,536 字符。结果超长时服务端改回一个 `isError` 结果说明原因；请求超长时客户端不发，抛 `McpRequestTooLargeException`。
- **失败的区分**（给 Extension Host 映射成 Completed / NotDispatched / Unknown）：`McpRpcException`（服务端收到但没执行）、`McpClosedException(dispatched)`（连接关闭，请求是否已交给通道）、`McpTimeoutException`（已发出、结果未知）、`McpRequestTooLargeException`（没发出）。
- **体积**：测试插件 App 的 R8 release 包 `classes.dex` 285 KB（含 plugin-sdk、binder-channel、coroutines、serialization-json），没有 Ktor。
